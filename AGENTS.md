# Agent Rules

- Use English except for official CFDI/SAT names.
- Keep changes within the active phase in `PROJECT.md`.
- Run PHP, Composer, Artisan, Pint, and PHPUnit through Docker Compose.
- For each class, prefer one concise happy-path test and one concise failure-path test; use data providers for additional cases.
- Preserve unrelated work and update `PROJECT.md` when a phase changes.
